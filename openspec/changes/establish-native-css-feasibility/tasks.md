## 4. Evidence and validation

- [ ] 4.1 Capture matching visual states and compute/record meaningful discrepancies; verify actual focus, keyboard, scroll, and text-input behavior. **Partial evidence only, NOT gate completion:** original CALYRA JavaScript executes under real Blitz/Boa without modification, experimental patches restore synthetic document Escape and button focus, live single-select property semantics pass **9/9** native tests ([run 43699535417](https://github.com/AVANT-ICONIC/calyra/actions/runs/43699535417)), and **same-document Vello CPU** `select.value` update genuinely changes **732 pixels** ([run 43778999121](https://github.com/AVANT-ICONIC/calyra/actions/runs/43778999121), [permanent evidence](../../../docs/evidence/blitz-select-live/)). A subsequent [verified noneditable native `SelectData` experiment](https://github.com/AVANT-ICONIC/calyra/actions/runs/43783621933) removed the temporary editor in an isolated pinned upstream adapter, preserved [17 exact evidence files](../../../docs/evidence/blitz-select-readonly/) and changed **731 real Vello CPU pixels** on one `ScriptDocument`, with **9/9 native Rust/Boa tests passing**. A later [exact-head idempotent-setter regression](https://github.com/AVANT-ICONIC/calyra/actions/runs/43865517201) passed **10/10 compiled native Rust/Boa tests**, archived [11 separate source/log files](../../../docs/evidence/blitz-select-idempotent/) and skipped needless direct redraw requests from unchanged JS selection assignments. No new pixel/performance or OS-input gate was claimed by that idempotence run. A further source-pinned option-text invalidation experiment passed **11/11 actual Rust/Boa tests** in [producing CI #43868624637](https://github.com/AVANT-ICONIC/calyra/actions/runs/43868624637), including synchronous `option.textContent` and direct Text-node `nodeValue` updates without changing selectedness or dispatching `input`/`change`. Real 1060×800 same-document Vello CPU frames differed at **381 RGB pixels** in bbox **[767,490,832,505]**. The producing job's only failure was a stale **archive-only** expected-label assertion; [independent archival CI #43871323400](https://github.com/AVANT-ICONIC/calyra/actions/runs/43871323400) PASSED and permanently verified [18 original files](../../../docs/evidence/blitz-select-option-text/). This supports only the two directly tested text mutation setters, not arbitrary DOM/CSS invalidation. A further [source-pinned computed-typography CI #43919838241](https://github.com/AVANT-ICONIC/calyra/actions/runs/43919838241) then **PASSED 12/12 compiled native Rust/Boa tests** and produced **1,639 real changed Vello CPU pixels**, bbox **[688,483,833,507]**, on one **1060×800** document after CSS-only `font-size` changed to `32px` while `select.value`, `selectedIndex` and label text remained identical. Parley label height changed **19→38 px** and to **21 px** on shrinking to `18px`; unrelated background-only style change did not invalidate the computed typography signature. **19 original SHA-256 checked artifacts** were [archived in the same successful run](../../../docs/evidence/blitz-select-typography/). This is a restricted CSSOM font-size proof, not verified class/inherited CSS/font-loading, true popup/OS/a11y/GPU behavior, or any performance claim; its full-tree fingerprint scan is a known unmeasured cost. All results depend on experimental upstream patches; neither is a production-ready widget. **Physical OS pointer/keyboard, IME safety, accessibility, actual dropdown, CSS parity, hardware GPU, matching mobile screenshots and complete focus/scroll input acceptance are NOT demonstrated.**
